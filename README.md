# Wireframe — Dr. Rafael Monteiro

Protótipo estático e responsivo para apresentação, criado a partir da copy fornecida.

## Uso
Abra `index.html` ou sirva esta pasta em um servidor HTTP. Não requer instalação nem build.

## Conteúdo
11 seções; menu móvel; condições e FAQ em sanfona; divisores curvos; botão pulsante com seta; retratos, galeria e avaliações reservados.

## Campos pendentes
Fotos, CRM, RQE, formação, endereço, telefones, convênios, horários, avaliações, textos completos de artigos e políticas legais. Os botões dessas integrações abrem avisos de demonstração, sem enviar dados. Não há agendamento real.

## Publicação
GitHub Pages: branch `main`, pasta raiz. Caminhos relativos compatíveis com o endereço do repositório. O protótipo solicita `noindex`; isso não substitui controle de acesso.
